**# Personal Expense Manager (Expense Tracker)

## 📌 Problem Statement
Managing personal finances can be challenging without a structured system. People often lose track of income and expenses, leading to poor budgeting and financial planning.

## 🎯 Objective
To build a simple Python-based local application that allows users to record, manage, and analyze their income and expenses with persistence.

## ✨ Features
- Add income and expense transactions
- Categorize transactions (e.g., Food, Rent, Salary)
- View transaction history
- Search and filter transactions by category
- Delete transactions
- Generate summaries:
  - Total income
  - Total expenses
  - Remaining balance
- Data persistence using JSON file storage

## 🛠 Technologies Used
- Python 3
- JSON for local storage
- Unittest for testing
